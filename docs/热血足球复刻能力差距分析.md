# 热血足球复刻能力差距分析

> 目标不是照搬名称、美术或关卡，而是复刻 FC《热血足球》那种“少人数街机足球 + 格斗抢球 + 必杀射门 + 场地天气干扰 + 锦标赛推进”的玩法手感。

## 参考基准

本分析以 FC / NES 的《Kunio-kun's Nekketsu Soccer League》和前作《Nintendo World Cup / Soccer Story》的核心机制为对照：

- 少人数制比赛，队伍通常为 5 名场上球员 + 守门员。
- 没有正规足球的犯规、越位等约束，铲球和攻击是核心抢球手段。
- 每名角色/队伍有鲜明属性、AI 性格、覆盖范围和专属必杀射门。
- 必杀射门可以通过跳跃踢球、倒钩/头球、带球步数或特定时机触发。
- 不同场地和天气会改变跑动、摩擦、积水、球路和控球稳定性。
- 单人主线以联赛/杯赛推进，对手逐步升级，后期队伍强度和必杀威胁明显变高。

## 核心差距总览

如果以“像热血足球”为目标，目前项目已经完成了大约 55%-65% 的底层玩法骨架；但离“玩家一上手就觉得是热血足球精神续作”还差几块很关键的味道：

1. 场地/天气系统缺失。
2. 角色个性和队伍差异还不够强。
3. 必杀触发规则偏现代蓄力，缺少原作的时机、步数、队伍专属招式。
4. 格斗抢球只有铲球和受伤，缺少更多攻击、击飞、倒地、爬起、眩晕。
5. 守门员缺少热血式强防守、被球轰飞、专属动作。
6. 锦标赛有框架，但缺少原作式路线、对手强度曲线、赛前信息和奖励解锁。
7. 场面反馈还不够夸张：慢停、屏震、残影、角色叫喊、爆炸、泥水/雪地滑步。

## 功能矩阵

### 1. 比赛规则与节奏

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 6 人制街机足球 | 已具备，每队 6 人 | 基本满足 | P0 已完成 |
| 无犯规、无越位、可暴力抢球 | 部分具备，铲球可伤人 | 缺少明确规则表达、攻击多样性 | P1 |
| 上下半场/半场变化 | 当前是单段 2 分钟比赛 | 缺少半场、换边、场地积水变差 | P2 |
| 球出界/边界规则 | 当前更偏封闭场地 | 原作可简化，但需要明确边界体验 | P3 |
| 快速开球/进球后重置 | 已有开球、重置状态 | 需要更爽快的过场和站位动画 | P2 |

建议：

- 继续保持“街机封闭场地”方向，不必追求真实边线。
- 加入半场制时，顺便接入天气积累和场地状态变化。

### 2. 操作与动作

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 跑动、传球、射门 | 已具备 | 传球目标选择还偏简单 | P1 |
| 铲球抢球 | 已具备 | 需要命中反馈、吹飞、倒地、硬直分层 | P0/P1 |
| 跳跃 | 已具备，PASS + SHOOT | 原作 A/B 按键映射不同，但精神接近 | P0 已完成 |
| 头球/倒钩/凌空 | 已具备 | 需要更稳定的球高判定和动作窗口反馈 | P1 |
| 指令队友传球/射门/抢断 | 部分具备：无球传球可请求/换人 | 缺少“命令 AI 队友射门/铲球”的热血感 | P1 |
| 冲刺/急停/滑步 | 不明显 | 原作节奏里冲刺和地面影响很关键 | P2 |
| 蹲下/特殊攻击输入 | 暂无 | 多数热血特殊技需要类似输入层 | P2 |

建议：

- 先补“无球队友指令”：按传球请求持球队友传球，按射门命令持球队友射门，防守时命令最近 AI 铲球。
- 给空中动作加可视化窗口，例如球可头球时角色脚下/头顶短闪。

### 3. 必杀射门

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 角色/队伍专属必杀 | 已有 `power_shot_type`，但更像队伍/球员配置 | 缺少角色独特命名、触发演出和强弱差异 | P0/P1 |
| 跳跃踢球触发必杀 | 部分具备：跳射有强力加成，可触发 PowerShot | 触发条件不够“时机感” | P1 |
| 倒钩/头球触发必杀 | 部分具备 | 原作重点是击球时机，当前更偏状态判断 | P1 |
| 带球步数触发必杀 | 暂无 | 热血味关键缺口 | P1 |
| 备用/通用必杀球路 | 部分具备：NORMAL/HEIGHT_LIGHT 等 | 需要按距离改变落点/弹跳策略 | P2 |
| 必杀消耗/风险 | 部分具备 HP 字段，但未形成消耗闭环 | 原作有体力/受伤压力，需要玩法化 | P1 |

建议实现顺序：

1. 增加 `dribble_step_count`：持球跑动一定步数后普通射门变必杀。
2. 增加“完美时机窗口”：跳跃接球在峰值附近射门才触发专属必杀。
3. 给每个国家/核心球员命名必杀，例如强力、隐身、地滚球、香蕉弧线、分身球等。
4. 必杀造成守门员硬直/击退，但强度受距离、体力、场地影响。

### 4. 格斗、受伤与倒地

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 铲倒对手 | 已具备基础 | 缺少倒地持续、翻滚、爬起、短暂无敌 | P0 |
| 球击中造成伤害 | 部分具备：HP、球伤害相关字段 | 伤害反馈和濒死状态不完整 | P1 |
| 多种攻击动作 | 暂无或很少 | 缺少膝撞、肩撞、钻头冲撞、守门员拳击等 | P2 |
| 角色被击飞/击倒 | 有 TODO 和 HURT 状态 | 需要完整状态链：HURT -> DOWN -> RECOVER | P1 |
| 队友/对手碰撞混战 | 部分 | 需要更夸张的碰撞规则 | P2 |

建议：

- 把当前 `HURT` 拆成轻伤硬直、倒地、爬起三个阶段。
- 铲球命中时不只是切 HURT，还根据速度/力量给击退速度。
- 守门员被必杀射门击中时进入专用 `GOALIE_BLOWN_AWAY` 或 `DIVING_STUN`。

### 5. 场地与天气

这是当前最大缺口。

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 草地、泥地、沙地、冰/雪等场地 | 暂无实际差异 | 缺少地面摩擦、跑速、球滚动差异 | P0/P1 |
| 雨雪天气 | 暂无 | 缺少随机天气和视觉效果 | P1 |
| 积水/湿滑影响 | 暂无 | 原作味道核心 | P1 |
| 场地状态跨半场恶化 | 暂无半场系统 | 缺少“越踢越乱”的变化 | P2 |
| 场地影响必杀成功率 | 暂无 | 可作为高级玩法 | P2 |

建议数据模型：

```gdscript
class_name FieldCondition

enum Surface { GRASS, DIRT, SAND, ICE, MUD }
enum Wetness { DRY, DAMP, WET, FLOODED }
enum Weather { CLEAR, RAIN, STORM, SNOW }

var surface: Surface
var wetness: Wetness
var weather: Weather
var player_speed_multiplier: float
var ball_friction_multiplier: float
var slip_chance: float
var bounce_multiplier: float
var power_shot_success_modifier: float
```

优先做 3 个场地就够：

- 草地：标准体验。
- 泥地/雨地：跑动减速、停不住、球减速快、容易滑倒。
- 冰/雪地：摩擦低、急停困难、球滑更远。

### 6. 队伍、角色与 AI 性格

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 多队伍 | 已有 9 个国家 | 数量足够，但队伍差异还偏数值 | P1 |
| 角色属性 | 有速度、力量、HP、位置、必杀类型 | 缺少防守、攻击、体力、性格、覆盖范围 | P1 |
| AI 性格 | 暂无明确性格 | 原作有听话、固执、调皮、随机等行为差异 | P1 |
| 位置覆盖范围 | 有角色位置和 on-duty weight | 需要显式 coverage 数据 | P2 |
| 队长/核心球员 | 暂无明确队长机制 | 缺少核心角色辨识度 | P2 |

建议扩展 `PlayerResource`：

```gdscript
var offense: float
var defense: float
var stamina: float
var behavior_type: BehaviorType
var coverage_type: CoverageType
var captain: bool
var special_moves: Array[String]
```

AI 性格建议：

- Obedient：总是响应传球/射门/抢断指令。
- Stubborn：更爱自己射门，不喜欢传球。
- Naughty：可能不响应，偶尔做高风险动作。
- Fickle：随机性强，适合制造热血足球的混乱感。

### 7. 守门员

| 热血足球能力 | 当前状态 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 守门员 AI | 已具备基础防守/扑救 | 需要更强的热血式扑救表现 | P1 |
| 被必杀球轰飞 | 暂无明确状态 | 核心爽点缺失 | P1 |
| 守门员专属攻击/拳击 | 暂无 | 可后置 | P2 |
| 接球、脱手、二次反应 | 不完整 | 会影响射门层次 | P2 |

建议：

- 普通射门：守门员可接住或扑出。
- 高威力射门：守门员击退、短暂硬直，球可能继续进门。
- 必杀射门：根据守门员防守值、球威力、距离决定接住/弹飞/被轰飞。

- 获胜后可解锁队伍/必杀说明/难度。

- 场地天气：雨滴、雪花、泥水溅起比复杂 UI 更优先。

## 建议里程碑

### M1：先把“热血味”打出来

目标：不改大结构，快速补齐最显眼的差距。

- 铲球命中反馈：击退、倒地、爬起、短暂无敌。
- 带球步数触发必杀。
- 跳跃/头球/倒钩的完美时机窗口。
- 守门员被强力球击退。
- 必杀触发时的暂停、屏震、球光效和专属音效。

### M2：场地天气成为玩法

目标：让每场比赛有变化。

- 新增 `FieldCondition`。
- 草地、雨地、冰/雪地三套参数。
- 玩家跑速、急停、滑倒、球摩擦受场地影响。
- 雨雪视觉和水花/雪尘反馈。

### M3：队伍差异与单人流程

目标：让队伍不只是换皮。

- 扩展球员属性：进攻、防守、体力、性格、覆盖范围。
- 每队 1-2 个特色必杀或行为。
- 锦标赛路线固定化，后期队伍使用更强必杀和特殊场地。
- 队伍选择界面显示能力和必杀说明。

### M4：联机稳定和完整体验

目标：让核心热血玩法能在线同步。

- 必杀球路、击飞、倒地、守门员硬直全部服务端权威。
- 客户端只做预测和表现，不重复触发状态。
- 增加断线 AI 接管、重连、结果同步。
- 修复所有绝招动画与快照时序问题。

## 结论

当前项目最强的是：少人数足球骨架、空中动作、多种必杀球、基础 AI、锦标赛和联机同步雏形。这些已经接近“热血足球”的底层方向。

当前最缺的是：场地天气、角色个性、格斗倒地链、必杀触发时机、守门员被轰飞、赛事包装。只要优先完成 M1 和 M2，游戏的主观体验会从“带必杀的 2D 足球”明显转向“热血足球精神续作”。
